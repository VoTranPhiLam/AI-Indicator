│ 📊 HIỂU KẾT QUẢ - UNDERSTANDING RESULTS                               │
└────────────────────────────────────────────────────────────────────────┘

    Chỉ số tốt:
    ✅ Total Profit:    > 0 pips (càng cao càng tốt)
    ✅ Win Rate:        > 50% (tỷ lệ thắng)
    ✅ Profit Factor:   > 1.5 (lời/lỗ)
    ✅ Max Drawdown:    < 20% (rủi ro)
    ✅ Score:           Càng cao càng tốt

┌────────────────────────────────────────────────────────────────────────┐
│ 🔧 TÙY CHỈNH - CUSTOMIZATION                                          │
└────────────────────────────────────────────────────────────────────────┘

    Sửa trong file: backtest_optimizer.py

    1. Thay đổi TP/SL:
       tp_pips = 30.0    # Take Profit
       sl_pips = 10.0    # Stop Loss

    2. Thay đổi khoảng test:
       param_grid = {
           'rsi_period': list(range(10, 21)),  # 10-20
           'overbought': [70, 80],             # 2 giá trị
           'oversold': [20, 30]                # 2 giá trị
       }

    3. Dùng dữ liệu của bạn:
       data_file = 'TEN_FILE_CUA_BAN.csv'
